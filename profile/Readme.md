# Spring Fest Tech Projects

This repository showcases the major tech projects developed by the Spring Fest Tech Team at IIT Kharagpur. From full-stack development to app deployment, these tools powered one of India's largest college cultural festivals.

---

## 🚀 Projects

### 📱 Spring Fest App
A comprehensive mobile app for the fest with features like event registration, schedules, interactive maps, and more.  
**Google Play Store:** [Spring Fest App](https://play.google.com/store/apps/details?id=com.imaginedtime.sf25app)

### 🌐 Spring Fest Website
The official website serving as the digital face of the festival.  
**URL:** [https://springfest.tech](https://springfest.tech)

### 📱 Mobile Website
Optimized for smartphones with a fast, responsive UI.  
**URL:** [https://m.springfest.tech](https://m.springfest.tech)

### 🧑‍🤝‍🧑 Teams Portal
Platform for managing team registrations and submissions for various events.  
**URL:** [https://teams.springfest.tech](https://teams.springfest.tech)

---

## 🗄️ Backend & Admin Panel

The backend infrastructure is hosted at:  
**Admin Portal:** `https://masterapi.springfest.in/admin`

> ⚠️ This is an internal CRM (Content & Resource Management) system used by the core organizing team to manage events, participants, teams, schedules, and more. It is not publicly accessible for security and privacy reasons.

---

## 🌍 Domain Information

- **Primary Development Domain:** `springfest.tech`  
  (used for active development and internal deployment)
- **Official Fest Domain:** `springfest.in`  
  (used during the fest for public-facing content)

## 📝 About

These tools were built collaboratively by the Spring Fest Tech Team to streamline event management, enhance the participant experience, and provide a seamless digital infrastructure for the fest.
